# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for a security problem (remote crash, authentication bypass, SQL injection, packet exploit, duplication exploit, and similar).

Report it privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Include the affected commit, the client build, and the steps to reproduce.

You will get an answer as soon as a maintainer has looked at it. Please give us reasonable time to publish a fix before you disclose the details.

## Supported versions

Only the latest commit on `main` receives security fixes.

## Secrets

This repository never contains real credentials. If you find a password, token, private key or server address committed here, report it the same way.
